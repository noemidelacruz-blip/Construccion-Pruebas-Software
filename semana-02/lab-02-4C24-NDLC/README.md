Laboratorio 2 para el curso de Construcción y Pruebas de Software. En esta práctica se trabaja con el manejo de comandos básicos de Git, gestión de repositorios locales y remotos, uso de archivos .gitignore y versionado de cambios.

## Getting Started

Para empezar a trabajar con este proyecto en tu entorno local:

1. Clona el repositorio utilizando el comando:
   git clone https://github.com/noemidelacruz-blip/Construccion-Pruebas-Software.git

2. Navega hasta la carpeta del laboratorio:
   cd Construccion-Pruebas-Software/semana-02/lab-02-4C24-NDLC

3. Revisa el estado del repositorio y la configuración del .gitignore con:
   git status
